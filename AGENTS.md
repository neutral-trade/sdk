## Company brain

Before starting work, read `~/brains/neutral/map.md`. If the local copy is unavailable, read the [map in neutral-trade/cerebro](https://github.com/neutral-trade/cerebro/blob/main/map.md). If the brain and the code disagree, follow the code.

When knowledge you need is missing or wrong, open an issue on `neutral-trade/cerebro` with the `flag` label. State what you needed and what you found, and link to the evidence.

Fill in the Learned section on every PR. “None” is a full answer.
